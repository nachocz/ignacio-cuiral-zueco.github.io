How it works

Interaction guide

Objective: Adjust the joints until the cable follows the dashed target.

Controls: Each slider rotates one robot joint; both robots shape the same cable.

Feedback: The current error and history show whether your change helped. Lower is better.

Research context

Manipulating flexible objects is a central robotics challenge with uses in homes, agriculture and manufacturing.

Limit: Some target shapes are unreachable because of material and robot constraints—characterizing that reachable set remains an open problem.

Takeaway Flexible-object control couples every action to the whole shape.

You used visual feedback and trial-and-error. An autonomous controller must discover the same action-to-shape relationship and update it as the object changes.
