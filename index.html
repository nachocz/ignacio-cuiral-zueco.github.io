Research agenda

Research

I study how robots perceive, model, and control deformable objects. My work connects shape perception, mapping, and manipulation with a focus on robust, data-efficient methods and multi-robot coordination.

  • Main research line: Shape control.
  • Core topics: Shape control, deformable object manipulation, robot perception, and visual servoing.
  • Applications: Robotic manipulation, cooperative robotics, and manufacturing.

Interactive Demos: For a more accessible introduction to my research, check out the section with interactive visualizations designed for a general audience.

05

Demos & outreach

Dissemination

Four interactive demonstrations of deformable-object shape control, followed by my educational robotics and outreach work.

Four demonstrations

Shape control of deformable objects

The demonstrations build up a single control loop: manipulate a deformable object by hand, quantify how close two shapes are, choose the features that define shape error, then estimate the shape Jacobian and close the loop.

The demonstrations are ordered, but each one stands alone.

Step 1 · Manipulate

Manual shape servoing

Two planar manipulators hold a deformable linear object at both ends. Moving either gripper changes the shape of the whole object.

Task: Move one gripper or rotation ring at a time and keep the change only when the shape error decreases.

The same manipulators, rod model and target return in step 4, where an estimated Jacobian replaces the operator.

Explore the research: object-compliant shape control · multiscale 3-D shape control

Step 2 · Compare

Measuring shape similarity

Any correction loop needs a scalar that states how far the current shape is from the target. This demonstration makes that measurement explicit.

Task: Remove material, measure again, and undo an edit that lowers the score: the compare-and-correct step a controller repeats.

The score used here is a simple area overlap. Shape control on real deformable objects needs correspondence-aware metrics.

Explore the research: time-consistent surface mapping · elastic contour mapping

Step 3 · Represent

Shape representations and invariance

The same geometry can be described by point coordinates, edge vectors or discrete curvature. Each description defines a different error signal.

Task: Translate, rotate and bend the object, and compare which of the three error signals responds.

Invariance is a design choice: it rejects nuisance motion, but also removes degrees of freedom the controller can observe and correct.

Step 4 · Shape control

Data-driven shape control

The same manipulation task, now closed by an estimated shape Jacobian and a feedback law.

Task: Identify the local model, run the controller under each representation, and compare the commands and error signals.

The offline phase estimates how gripper motion maps to shape change; the online phase applies that estimate as feedback and keeps updating it.

Explore the research: data-driven shape trajectory control
